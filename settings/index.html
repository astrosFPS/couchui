Phone remote

Pair your phone with KDE Connect to use it as a trackpad and keyboard — useful for web pages a controller can't navigate.

KDE Connect isn't installed. Install it, then reopen this page:

sudo apt install kdeconnect

You'll also need the KDE Connect app on your phone, on the same Wi-Fi network.

Using it as a mouse

Once paired, open KDE Connect on your phone, select this machine, and choose Remote input. Swipe to move the pointer, tap to click, and use the keyboard button to type.

If the phone can't find this machine, the firewall is the usual cause — KDE Connect needs ports 1714–1764 (TCP and UDP):
sudo ufw allow 1714:1764/udp && sudo ufw allow 1714:1764/tcp
